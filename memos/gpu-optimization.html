04Haladó & Extra Tippek
CPU affinitás beállítása
Task Manager → Részletek → jobb klik → Set Affinity. Régebbi CPU-n: hagyd az összes magot bejelölve.
BIOS: XMP / EXPO RAM profil engedélyezése
RAM sebesség kritikusan befolyásolja a CPU bottleneck-et. DDR4: 3200+ MHz sokkal jobb mint az alap 2133 MHz.
GeForce Experience: Automatikus optimalizálás KI
GFE néha rosszul optimalizál. Overlay is legyen KI: Alt+Z → Beállítások → Általános.
Driver: Clean install
GeForce.com → Game Ready Driver → Custom install → Perform clean installation pipa be.
Fullscreen: Exclusive mód
Mindig Exclusive Fullscreen, ne Borderless Windowed. Közvetlen GPU hozzáférés, kevesebb DWM overhead.
NVIDIA Reflex (ha támogatott)
Competitive játékokban (Fortnite, Valorant, Apex) kapcsold BE. Csökkenti render latenciát CPU bottleneck esetén is.
