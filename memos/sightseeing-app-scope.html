App célja

Utazástervező app: a felhasználó megadja az úti célt, napok számát, főket és utazási eszközt, kiválasztja az érdeklődési köröket, az app pedig generál egy napi bontású útvonaltervet és szállásajánlatokat.

04
Wizard lépései
1. lépés — Alapadatok: Honnan / Hova / Hány nap / Hány fő / Utazási eszköz
2. lépés — Érdeklődési körök: Fix kategória checkbox kártyák (múzeum, étterem, látnivalók, természet, bevásárlás, éjszakai élet, templomok, történelem) — kártya formátum, ikon + leírás
3. lépés — Eredmény: Párhuzamos napi timeline (reggel/délben/este oszlopok) + szállás-kártyák alul + "Újratervezés" gomb
05
Claude API hívás struktúra

Egy JSON hívás, strukturált output. A prompt tartalmaz: városnév, napok száma, főre, utazási eszköz, kiválasztott kategóriák. Claude visszaad egy JSON-t a következő struktúrával:

{ days: [ { day: 1, title: "...", morning: { name, description, duration, tip }, lunch: {...}, evening: {...} } ], hotels: [ { category: "budget|mid|premium", name, area, note } ] }
06
Booking.com deep link formátum
https://www.booking.com/searchresults.html?ss={város}&checkin={dátum}&checkout={dátum}&group_adults={főre}&nflt=class%3D{csillag}

Budget: class=1-2, Mid: class=3, Prémium: class=4-5. Dátum alapértelmezett: mai nap + 30 nap.
