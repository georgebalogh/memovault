02 Telepítés — Ollama

ollama pull <model:tag>
// custom context variant (Modelfile)
@"
FROM <base-model>
PARAMETER num_ctx 16384
"@ | Out-File -Encoding ascii Modelfile-xxx
ollama create <new-name> -f Modelfile-xxx
// lista / törlés
ollama list
ollama rm <model>
